WITHIN THE LATENT WALLS / ENTRE LES MURS LATENTS
================================================

Setup includes the native game, assets, fonts and runtime libraries, without
model weights. After copying these files, it downloads Gemma 4 E4B (5.34 GB)
from Hugging Face into the game's models directory and verifies its SHA-256.
An Internet connection is required for this final installation phase; no
account is needed. An existing model is reused only after size and SHA checks.
If the download fails, retry or run Setup again. A partial or invalid model
is not accepted. An interrupted download may restart from the beginning.
After installation, the game runs locally without a network connection.
Distribute the single Setup executable; no .bin volumes are required.
The explicit complete portable build already includes the verified model and
runs directly through WithinTheLatentWalls.exe without an installation download.

Windows 10 x64 version 1809 or newer is required. Allow at least 8 GB of free
disk space for a fresh installation, plus space for research archives. The
smaller Setup does not reduce the installed model's size. A GPU whose current driver supports
Vulkan 1.2 (NVIDIA, AMD or Intel) is required for playable response times.
Vulkan SDK, Python and compilation tools are not required on the player PC.

Choose your language on launch. Every launch starts a fresh exploration.
Only the first place is predefined. Research descriptions, scene programs and
images are written under Local AppData/WithinTheLatentWalls/research.
These archives never initialize the next game and survive uninstallation.
