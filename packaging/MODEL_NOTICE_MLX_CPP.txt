WITHIN THE LATENT WALLS - NATIVE MLX MODEL NOTICE
================================================

This macOS application evaluates Gemma 4 E4B Instruct locally with MLX C++/Metal.
It contains the pinned affine 4-bit Safetensors checkpoint from mlx-community.
Only text tensors are evaluated. No interpreter, account or server is required.
All model artifacts are checked against the embedded SHA-256 manifest before use.
