## API à tester (sera implémentée par Codex)

Le nouveau header `narrative_language.h` (absent de votre base) inclura game_state.h et string. Namespace liminal :

```cpp
std::string NarrativeLanguageInstruction(GameLanguage language);
bool IsClearlyWrongNarrativeLanguage(const std::string& text, GameLanguage expected);
const char* LocalizedDirectionLabel(CardinalDirection direction, GameLanguage language);
```

La première fonction donne une instruction système dans la langue choisie (anglais, français, norvégien bokmål, danois, allemand, italien). Vérifier non vide et distincte pour chaque langue, sans imposer une formulation exacte.
La deuxième est un garde lexical conservateur, pas un classifieur universel. Vérifier que des paragraphes naturels de 30–50 mots écrits dans chacune des six langues ne sont PAS rejetés dans leur propre langue. Vérifier le rejet d'un paragraphe clairement français pour italien et anglais, italien pour français, anglais pour italien, allemand pour français. Ne pas exiger de distinguer danois/norvégien sur des phrases ambiguës. Les chaînes vides, chiffres, noms propres courts et titres ambigus comme "Eryx" doivent rester acceptés.
La troisième donne les noms complets : EN North/East/South/West ; FR Nord/Est/Sud/Ouest ; NO Nord/Øst/Sør/Vest ; DA Nord/Øst/Syd/Vest ; DE Nord/Ost/Süd/West ; IT Nord/Est/Sud/Ovest. Vérifier les 24 couples exactement.

Régression réelle : en session italienne, le modèle a produit : "Vous tentez de progresser vers le sud, mais la masse angulaire de quartz vous arrête. Le silence de ce chantier planétaire est absolu, une pression lourde contre la coque de votre combinaison. Vous restez là, face à la froide immobilité de la roche." Ce paragraphe doit être rejeté pour italien et accepté pour français.
