## Résolution des commandes

L’appelant fournit déjà un texte normalisé en minuscules ASCII, accents rabattus, ponctuation remplacée par espaces et espaces compactés. Ne pas refaire de normalisation Unicode. Aucun regex nécessaire. Préférer des petites tables et comparaisons exactes ; pas de correspondance par sous-chaîne pour les noms. Pas de recherche globale du projet.

List reconnaît exactement : i, inventaire, inventory, inventar, inventario, mon inventaire, consulter inventaire, consulter l inventaire, afficher inventaire, afficher l inventaire, qu est ce que je porte, que porte je, que transportez vous, que transporte je, what am i carrying, what do i carry, hva har jeg med meg, hvad har jeg med mig, was trage ich bei mir, cosa porto con me. Ne pas confondre « utiliser inventaire » ou « inventaire secret du lieu » avec List.

Inspect : préfixes examiner/regarder/inspecter/inspect/examine/look at/untersuche/betrachten/se pa/undersok/undersog/esamina/guarda. Take : prendre/ramasser/take/pick up/nehmen/ta/tag/prendi/raccogli. Drop : poser/deposer/jeter/donner/drop/discard/give/ablegen/wegwerfen/legg fra deg/laeg/slip/posa/lascia/getta. Use : utiliser/use/benutzen/bruk/brug/usa/utilizza. Retirer un préfixe de politesse facultatif je veux/je voudrais/je/i want to/i would like to avant résolution. Préfixes les plus longs avant les courts, suivis d’un espace ou fin de texte.

Après un verbe : retirer un article possessif/défini simple au début (la/le/les/l/ma/mon/mes/the/my/der/die/das/meine/den/det/min/mit/il/lo/gli/le/mio/mia). Résoudre ensuite le reste EXACT vers une identité ou un alias :
- tablette/carte/tablette cartographique/carte topographique/slate/map/map slate/survey map slate/kartbrett/kart/kort/kartentafel/karte/tavoletta/mappa/tavoletta cartografica ;
- craie/craie de delimitation/chalk/boundary chalk/kritt/kridt/kreide/gesso ;
- pinces/pince/pinces a echantillons/tongs/sample tongs/provetang/probenzange/pinze/pinze per campioni.

Un nom connu avec verbe Inspect/Take/Drop/Use => commande + id. Inspect sans cible ou avec plusieurs objets (« examiner la craie et les pinces ») => Ambiguous, id vide. Inspect visant un objet inconnu (« examiner le ciel ») => None pour préserver l’observation normale. Take/Drop/Use sans cible ou cible inconnue => même commande avec id vide ; le moteur donnera un refus/une clarification, sans LLM ni faux effet. Ainsi « prendre le portail » est Take avec id vide, « prendre la craie avec les pinces » ne devient pas prendre craie.

Nom seul d’un objet connu => Inspect. Toute autre phrase => None. Ne pas interpréter « j ai trouve une cle » comme acquisition. Pas de résolution approximative risquant de choisir un autre outil.
