## Correction essentielle par rapport à DUO-035

`proposed` contient les quatre directions. **`fixed` est une carte PARTIELLE.**
Une entrée absente signifie libre ; false signifie fermeture imposée.
Pour ne fixer que le retour, écrire `ExitMap fixed{{"north",true}}`.
Pour imposer aussi ouest fermé, écrire `{{"north",true},{"west",false}}`.
Ne JAMAIS utiliser `MakeExits(true,false,false,false)` pour le retour seul :
cela verrouille les trois autres directions et interdit de les ouvrir !
La première livraison commettait cette erreur dans presque tous ses tests.
