## Correctif produit

Le seuil ouvre nord, est et sud. Lors d'une découverte locale, le moteur parcourt
les lieux accessibles et compte les directions ouvertes sans voisin connu,
en excluant celle empruntée. Les liens existants, les barrières même non encore
observées et les pièces inaccessibles ne sont pas des réserves d'exploration.

Si aucune autre issue ne reste, l'audit géométrique exige une approche nouvelle,
hors retour. Le moteur fixe ensuite deux issues parmi les approches possibles,
ou une si une seule est praticable. La sélection tourne parmi les directions
relatives selon la graine ; elle n'impose pas un couloir cardinal fixe.
Le prompt et le schéma JSON reçoivent ces valeurs avant narration. Leur état de
secours est déjà ouvert si le modèle échoue ou propose de les fermer.

Les réservations sont conservées dans la provenance du lieu, validées à la
relecture et reprises pour résoudre une narration en attente. Une revisite ne
recompose pas le décor. Une géométrie sans continuation sur la dernière branche
est refusée dans le budget existant de trois compositions ; un échec complet
laisse le joueur au lieu précédent avec son issue encore inexplorée.
