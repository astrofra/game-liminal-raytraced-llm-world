# DUO-052 — Revue du test de dialogue progressif

DeepSeek a livré une modification de `tests/dynamic_scene_test.cpp` dans le worktree
isolé. Deux appels `edit` ont visé ce seul fichier. Le résumé confirme le modèle
`deepseek-v4.1-flash:cloud`, trois outils utilisés (`view`, `grep`, `edit`), aucune
erreur d'outil et aucune autre écriture. Le journal relève aussi une lecture de
`src/dynamic_scene.h` pour la signature du callback, en plus des lectures listées.

Codex a repris les scénarios dans le test existant. La comparaison des préfixes
attendus vérifie directement l'ordre, le décodage d'un accent JSON et l'attente
d'un caractère UTF-8 complet. Un flux tronqué déclenche le secours et un refus du
callback annule le tour en préservant l'historique et la simulation. Le build
Release et les 15 tests CTest passent.

La recette Windows avec Gemma local a capturé plusieurs états intermédiaires
dans la fenêtre SDL. La première question a produit une seule réponse dans
l'historique. Une pression sur Échap pendant la seconde a retiré l'aperçu et
laissé l'état et l'historique identiques. Les deux requêtes de chaque conversation
sont dans l'archive, avec la génération interrompue pour la seconde. Les
commandes `inventaire` et `i` ont répondu sans inférence. Les captures, les états
et les traces sont conservés dans le dossier de preuves privé `DUO-052-sdl-03`.
