## Décision sur les constats

- D1, préfixe `[THINK]` : rejeté comme défaut. Le préfixe appartient au protocole du template et doit entrer dans le canal privé. Instruct rejette volontairement un canal de réflexion inattendu. Aucune fuite finale démontrée.
- D2, fragments : rejeté. L'exemple `[<` ne suit pas l'ordre des retraits décrit ; le runtime vérifie aussi la monotonie avant émission. Masquer un marqueur partiel puis rejeter un marqueur complet inattendu est le comportement voulu.
- D3, callback : clarification retenue, pas de correction sémantique. `false` signifie annulation ; un delta vide est un signal de vie. Le consommateur SDL consulte bien son drapeau d'arrêt sur ces appels. Contrat explicité dans l'en-tête et le guide.
- D4, délai : pas de cause erronée établie ; l'expiration prime volontairement sur une erreur de chargement. Les contrôles restent coopératifs et ne préemptent pas instantanément CUDA. Codex a ensuite ajouté un contrôle final et la consultation de l'annulation pendant le chargement. Le rapport limité aux extraits ne validait pas la phase finale complète.

Aucun correctif de code généré n'est intégré à partir de cet audit. La revue complète Codex et l'examen du parseur amont ont ensuite fait évoluer l'intégration : réflexion optionnelle, contrôle d'annulation au chargement et ultime vérification avant publication. Onze tests natifs réels passent après ces changements. Le rapport exécutant est conservé dans son worktree pour traçabilité ; il n'est pas présenté comme une liste de bugs confirmés.
